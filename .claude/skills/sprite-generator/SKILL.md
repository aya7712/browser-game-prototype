## 概要

UI アイコン・作物スプライト・タイルなど **64px 以下の小型ドット絵** を、
高解像度から縮小するのではなく **ネイティブ解像度で 1セル=1ピクセルとして直接描く**。
小さい素材はこの方が輪郭がくっきりし、狙った形に作り込める。

描画は「ASCIIグリッド + パレット辞書」で記述する。これは LLM が形を正確に
組み立てやすく、テキストとして差分も見やすいため。`scripts/pixel_tools.py` の
`save_sprite()` がグリッドを PNG 化し、目視確認用の拡大プレビューも書き出す。

大型の背景・シーン（タイトル背景、ダンジョン背景など）は対象外 → `bg-generator` を使う。

## ファイル配置

| ファイル | 説明 |
|---|---|
| `public/assets/<category>/<name>.png` | 本番ファイル（ネイティブ解像度）。`asset-list.md` のパス・サイズに従う |
| `/tmp/<name>-preview.png` | 目視確認用の拡大プレビュー（自動生成・リポジトリ非汚染） |

カテゴリ例: `ui/`, `crops/`, `farm/`, `dungeon/`。ファイル名とサイズは必ず
`docs/external-design/asset-list.md` の記載に合わせる。

## 手順

### 1. 仕様と配色を確認する

コードを書く前に次を読む:
- `docs/external-design/asset-list.md` — 対象ファイル名・サイズ・用途
- `docs/external-design/tone-and-manner.md` — カラーパレット・ビジュアルスタイル

色は原則トンマナのパレットから選ぶ。被写体を背景から際立たせるため、
枠線にはトンマナで定義されたテキスト主色系を使うとまとまりやすい。

### 2. ASCIIグリッドでドット絵を組む

`asset-list.md` のサイズと同じ行数・桁数のグリッドを作る（例 32×32 なら 32行×32桁）。
1文字 = 1ピクセル。`.` または半角空白は透明。それ以外の文字はパレットで色を定義する。

可読性のため、文字は「色の意味を連想できる」1文字にする（例: `w`=水色, `o`=枠線, `h`=ハンドル）。
小さい素材ほど **大きな色面とシルエット優先**。細かい描き込みは潰れる。

### 3. スクリプトを書いて実行する

`scripts/pixel_tools.py` を import する短い生成スクリプトを書く（`scripts/` 直下に置く）。
テンプレート:

```python
import sys
sys.path.insert(0, ".claude/skills/sprite-generator/scripts")
from pixel_tools import save_sprite

PALETTE = {
    ".": None,          # 透明
    "M": "#9aa0b0",     # 金属（スコップの先）
    "m": "#c8cdd8",     # 金属ハイライト
    "h": "#a0703c",     # 木の柄
    "o": "#4a3050",     # 枠線
}

GRID = [
    "................................",
    # …32行ぶん。形を直接ここに描く…
    "................................",
]

save_sprite(GRID, PALETTE, "public/assets/ui/icon-scoop.png", outline="#4a3050")
```

実行:

```bash
uv run --with pillow python3 scripts/gen_icon_scoop.py
```

`outline` を渡すと不透明部の外周に1px縁取りが付く（任意）。自分で枠線文字を
グリッドに描く場合は `outline=None`（既定）でよい。

### 4. プレビューを確認して作り込む

出力された `/tmp/<name>-preview.png` を Read で開いて形を確認する。
ネイティブPNG（32×32等）は小さすぎて目視に向かないため、必ずプレビューで見る。
気になる箇所はグリッド文字列を直接編集して再実行する。これを数回繰り返して仕上げる。

### 5. 報告する

本番PNGのパスとサイズをユーザーに伝える。プレビューは確認用の一時ファイルである旨も添える。

## 作成のコツ

- **左右対称な物**（コイン、丸アイコン等）は半分だけ丁寧に描いて目視で対称性を確認する。
- **1〜2色の濃淡 + 縁取り** で十分に立体感が出る。色を増やしすぎない。
- **作物の3ステージ**（芽・育成中・収穫可）はパレットを共有し、グリッドだけ差し替えると統一感が出る。
- **タイル**（64×64）は上下左右がシームレスに繋がるよう端のパターンを揃える。
- 透明背景を保ちたいので、塗らない部分は必ず `.`（透明）にする。
